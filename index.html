// About

I am a Linux Systems Administrator and Cloud Infrastructure Engineer with 3+ years of intensive hands-on experience in low-level Linux administration, POSIX systems engineering, server security hardening, and hybrid cloud operations across Microsoft Azure and AWS.

My engineering philosophy centers on understanding computing systems from the bottom up: hardware, firmware, kernel internals, memory management, POSIX syscalls, network protocols, and distributed resilience.

I maintain and operate 24/7 virtualized server clusters powered by bare-metal QEMU/KVM and Linux hypervisors. I actively diagnose and secure systems using deep network telemetry (TCP/IP, DNS, Nginx reverse proxies, UFW/Iptables, Fail2ban), and automate infrastructure using modern Bash and cloud-init.

// Projects & Code

I engineer systems software with an emphasis on low-level performance, lockless concurrency, and zero-dependency architectures. My work spans segmented POSIX download engines in C11, container runtimes built from scratch using Linux namespaces and cgroups v2 in Go, zero-dependency kernel telemetry daemons querying /proc, and asynchronous terminal user interfaces in Rust.
